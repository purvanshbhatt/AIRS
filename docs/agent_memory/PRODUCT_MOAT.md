# ResilAI Moat

We are NOT:
- Generic AI compliance software that hallucinates readiness
- Standard GRC software that relies on manual spreadsheets
- Simple questionnaire software

We ARE:
- Telemetry verified audit readiness
- Evidence-based compliance operations
- Continuous control verification via live data

Trust Principles:
1. **LLMs never score**. A hallucinated score destroys trust.
2. **Telemetry beats questionnaires**. Pulling data from Splunk/Wazuh is superior to asking humans.
3. **Evidence beats self-attestation**. If they say it's encrypted, show the configuration.
4. **Deterministic scoring only**. Scores are mathematical, traceable, and repeatable.

Competitive Targets:
- Vanta
- Drata
- AuditBoard

Differentiator:
The Verification Engine. While competitors rely on simple API hooks or manual uploads, we use deep telemetry analysis (Splunk/Wazuh) to continuously verify controls, and AI to translate those hard technical findings into board-level narratives.
