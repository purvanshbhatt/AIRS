# Product Vision

ICP: 
Series B security teams and enterprise compliance departments.

Core Philosophy: 
Evidence-first. We do not generate security scores out of thin air. We gather evidence through telemetry and integrations, then verify.

Product Moat:
Trust. The platform must be completely deterministic when calculating scores. 

GTM Strategy:
Targeting CISO dashboarding and automated compliance checking.

Design Partner Goals:
Seamless integration with Microsoft ecosystem, Wazuh, Splunk.
