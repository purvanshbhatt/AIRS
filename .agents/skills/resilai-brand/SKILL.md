# ResilAI Brand Skill 

Before generating any UI, you MUST read the following files:
- `docs/design/01_PRODUCT.md` 
- `docs/design/02_PAGES.md` 
- `docs/design/03_BRAND.md`

## Rules
- **Never** generate generic cybersecurity dashboards.
- Executive dashboard first.
- Technical workspace separate.
- Healthcare first.
- Use existing logo colors.
- Preserve the ResilAI identity.
- Apply "Apple Health" style storytelling.
- IT details belong in the Operations Center.
- **Every page answers:** "Are we ready today?"
