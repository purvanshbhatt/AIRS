# Pricing — ResilAI

Last updated: 2026-11-05. Canonical page: https://resilai.org/pricing. Billing through Stripe, USD, cancel anytime on self-serve tiers.

ResilAI is an agentless incident-readiness platform for small healthcare clinics and law firms. It connects read-only to Microsoft 365 / Entra ID, AWS Security Hub, Splunk, Wazuh, Veeam, Cisco Duo and custom webhooks, then produces a deterministic readiness score, a 1-page executive "boss report", and a cyber-insurance evidence binder.

## Founding Sysadmin / Design Partner
- Price: $149/month, locked for life for the first 50 customers (regular price $199/month)
- Billing: monthly, self-serve checkout
- Limits: up to 250 network nodes and endpoints, 1 organization, 1 administrator
- Includes: whole-network topology map and lateral-containment simulator, automated Monday-morning 1-page boss report, 1-click cyber-insurance underwriter binder (Coalition, Chubb, Travelers), 100% agentless ingestion (read-only PowerShell and AWS CloudFormation), continuous 24/7 deterministic scoring, direct founder channel, bi-weekly posture reviews
- Condition: one 20-minute onboarding screen-share with ResilAI engineers
- Start: https://resilai.org/pricing

## Growth
- Price: $399/month (regular $499/month); annual reference $3,990/year
- Billing: monthly, self-serve checkout
- Limits: up to 500 network nodes and endpoints, up to 5 administrators
- Includes: everything in Founding Sysadmin plus all 7 technology-domain products (Identity, Devices, Backups, Email, Network, Cloud, AI), multi-cloud telemetry (AWS, Azure/Entra ID, Google Cloud), drift alerting and webhook notifications, SHA-256 evidence ledger for auditors, Needs Attention triage with 1-click remediation, business-hours SLA
- Start: https://resilai.org/pricing

## Enterprise
- Price: custom contract — contact https://resilai.org/contact?tier=enterprise
- Limits: unlimited assets, multi-tenant organization hierarchy, RBAC
- Includes: everything in Growth plus dedicated Cloud Run instance or private VPC deployment, SSO/SAML and SCIM, custom framework mapping (NIST CSF 2.0, HIPAA, SOC 2, ISO 27001), full REST API and webhook ingestion, dedicated technical account manager, 99.9% uptime SLA

## Free
- Price: $0
- Includes: interactive demo workspace with simulated data (no live connectors, no real-organization scoring, no exports)
- Start: https://resilai.org/demo

## Frequently asked questions
- Agents on endpoints? No. Ingestion is 100% agentless (read-only PowerShell for Microsoft 365 / Entra ID / Defender, 1-click AWS CloudFormation).
- Contract? None on self-serve tiers; cancel anytime.
- Does confidential log data go to an LLM? No. Scoring is deterministic on-server; only normalized finding summaries reach Gemini for plain-English narrative.
- Supported connectors: Splunk, Wazuh, Microsoft Graph / Entra ID, AWS Security Hub, Veeam, Cisco Duo, custom JSON webhook.
