# ResilAI: Application Pages

## Landing Page
The public-facing marketing page that introduces ResilAI to healthcare executives. It focuses on the core value proposition of deterministic security and daily readiness, featuring a clean, premium, healthcare-oriented aesthetic that immediately builds trust.

## Login
A sleek, minimal authentication gateway for both executives and IT personnel. It supports standard email/password as well as enterprise SSO (Google/Microsoft) and sets the tone for a secure, high-end enterprise application.

## Today (Morning Brief)
The mobile-first, primary dashboard designed for executives. It answers the question "Are we ready for today?" immediately. It features a large, clear status indicator, a summary of overnight system verifications, and a high-level readiness score. 

## Needs Attention
A focused triage view highlighting the specific items, alerts, or failed checks that require immediate action to maintain operational readiness and compliance. It separates critical, blocking issues from minor warnings.

## Recovery
A dashboard tracking the clinic's ability to bounce back from an incident. It shows the status of recent backups, disaster recovery plans, system redundancy metrics, and the calculated Time to Recovery for critical patient databases.

## Documents
A centralized, secure repository for compliance paperwork, audit reports, system configurations, and policy guidelines. It allows users to view, download, and manage the essential documentation required for healthcare audits.

## Governance
A high-level view of the clinic's alignment with regulatory frameworks (like HIPAA). It tracks compliance drift, policy enforcement, and overall security posture scores, allowing leadership to prove compliance at a glance.

## Connectors
The management interface for third-party integrations (EHRs, Google Workspace, AWS, Identity Providers). It displays the real-time sync status and health of the APIs feeding data into the ResilAI verification engine.

## Operations Center (IT)
The technical workspace for IT administrators and MSPs. This deep-dive dashboard provides raw telemetry, infrastructure topology, detailed logs, and the tools needed to investigate issues flagged on the executive dashboard.

## Settings
The configuration hub for the application. It handles user management, role-based access control, notification preferences, billing, and clinic-specific configurations like operating hours or custom compliance thresholds.

## Ask ResilAI
An AI-powered conversational interface that allows users to ask natural language questions about their security posture, past audits, or how to resolve specific compliance issues (e.g., "Show me the backup logs from last Tuesday").

## Notifications
A drawer or dedicated page listing chronological system alerts, verification results, and team mentions. It categorizes alerts by urgency and allows users to mark items as resolved or escalate them to the IT team.
